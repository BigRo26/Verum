# Verum: Automated Fact-Checking Assistant

Chrome extension that uses multipart orchestration flow to analyze and verify claims in digital media via real-time audio analysis. Uses Whisper for transcription, a pre-trained classifier for claim identification, Tavily for context retrieval, and LLM for reasoning
